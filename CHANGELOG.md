# Changelog

## 0.1.0 — 2026-10-31

- Added runnable React/TypeScript/Vite browser application with real Three.js bridge rendering.
- Added authoritative deterministic fixed-step vessel simulation and shared navigation sensors.
- Added inertial rudder/engine, heading autopilot, current vectors and moving traffic.
- Added ideal training radar, CPA/TCPA target tracking, EBL/VRM, synthetic ECDIS and editable route.
- Added integrated controls, keyboard camera presets, weather, GPS dropout, local saves and training presets.
- Added production math/dynamics/time regressions and browser integration tests.
- Preserved the provided marine-navigation-qa Skill and its test suite.
- Documented model assumptions, calibration gaps and unsupported advanced systems.
