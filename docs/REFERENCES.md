# Equipment references and scope

Reference product families requested by the brief:

- Furuno FAR-2xx8: https://www.furuno.com/en/products/radar/far-2xx8/index.html
- Furuno FMD-3200/3300: https://www.furuno.com/en/products/ecdis-ins/fmd-3200-3300/
- IMO COLREG overview: https://www.imo.org/en/ourwork/safety/pages/preventing-collisions.aspx
- IHO: https://iho.int/

These are reference sources, not proof of a certified implementation. The current application uses an independently designed educational interface, no Furuno logos or firmware, and synthetic cartography. It does not reproduce undocumented brand-specific behavior. North-up/head-up presentation, range rings, EBL/VRM, CPA/TCPA and route monitoring are general navigation concepts. Product-specific UI replication and standards compliance require a separate documented validation stage.

The supplied bridge photograph informed arrangement and composition only. Geometry, screens, terrain and shaders are generated in code; no static bridge photograph is used in the running scene.
