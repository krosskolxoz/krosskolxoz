# Declared model and verification contract

Before implementation: local tangent coordinates are east/north metres around a fictional strait near 37.70 N, 122.48 W. Heading and bearings are degrees clockwise from true north. Body surge is forward m/s; sway is starboard m/s; yaw is clockwise degrees/s. Positive rudder is starboard. 1 kn = 1852/3600 m/s. Rendering maps [east,north] to [x,-z].

The 180 m, 30 m beam, 10 m draft bulk carrier is a **configurable, uncalibrated training model**, not a validated naval architecture model. Surge uses engine lag and quadratic drag: du/dt = (q·U - u·|u|/U)/95, where U is service speed and q is actual ahead engine fraction (astern fraction ×0.45²); first-order Nomoto yaw builds gradually toward K·rudder·speed effectiveness; sway relaxes toward a small outward drift. Rudder actuator rate is 2.3 degrees/s and limit ±35 degrees. Engine response time is 18 seconds; powered surge time scale is 95 seconds. Zero command leaves drag and momentum. Astern is limited to 45% of service speed. Current adds in world coordinates without changing heading. No bank effect, waves, wind force, squat, or propeller walk is claimed.

Simulation uses fixed 1/60 s steps. Wall deltas are scaled exactly once; accumulated time is never silently discarded. Catch-up is capped to 600 steps per call with backlog retained; UI requests another frame. Time scale is 0,1,2,4,8. Scheduled commands are applied at fixed-step boundaries.

Sensors: GPS/gyro/log/depth update at 1 simulation Hz with timestamp; noiseless ideal measurements, no transport delay. GPS dropout produces null position while gyro/log remain alive. Radar target geometry uses current truth; it is an ideal educational AIS-assisted tracker rather than a validated ARPA estimator. Trails sampled each second. Depth is synthetic chart bathymetry. Chart is fictional, not an ENC.

CPA: constant ground vectors over an unbounded horizon; signed TCPA retained, future TCPA clamped to zero; relative speed <= 1e-6 m/s has null signed TCPA and present range DCPA. Finite numbers required. Tests use independent hand-derived fixtures at 1e-8 m/s precision; determinism tolerances 1e-7 m position, 1e-8 degrees heading and 1e-9 m/s speed at equal step counts. Inertia tests use declared model bounds rather than claims of measured vessel fidelity.

Traffic: scripted desired headings with gradual rudder dynamics. Limited head-on/crossing avoidance orders a starboard turn when future CPA < 350m and 0<TCPA<180s, latched for 90 simulation seconds. This is an educational heuristic inspired by COLREG Rules 14/15/16, **not a COLREG compliance engine**. Restricted visibility, overtaking obligations, sailing vessels, constrained vessels and TSS are unsupported. Collision uses oriented rectangular hull footprints via separating axes; no collision response. The fixed timestep makes ordinary vessel speeds move far less than hull dimensions per step; swept continuous collision detection is not implemented.
