# BRIDGE MASTER

Рабочий браузерный тренажёр судовождения: трёхмерный мостик балкера, море, управление судном, движущийся трафик, учебные радар и электронная карта. Первый этап с частью навигационных систем второго/третьего этапов.

**SIMULATION ONLY — NOT FOR REAL NAVIGATION**

## Запуск

Требуется Node.js 22.12+ (проверено на 24) и браузер с WebGL2.

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://localhost:5173). Для production: `npm run build`, затем `npm run preview`. Приложение работает полностью в браузере, серверные API и внешние ресурсы во время сеанса не нужны.

## Что работает

- Настоящий процедурный 3D-мостик по композиции приложенной фотографии: панорамные окна, центральный штурвал, консоли, пять динамических кликабельных дисплеев, море, подвесной мост, берега и буи.
- Камера на фиксированной позиции: мышь для осмотра, колесо для FOV; F1–F4 переключают направления взгляда.
- Балкер 180 × 30 м, осадка 10 м; продольная инерция, боковое движение, постепенное накопление/затухание поворота, ограничение скорости перекладки руля, лаг двигателя и реверс. Настройки в `src/simulation/vessel-profile.json`.
- Ручное управление, 9 команд машинного телеграфа, автопилот удержания курса через общую модель руля.
- Четыре движущихся судна с инерцией и ограниченным алгоритмом уклонения вправо. Обнаружение пересечения корпусов; физика удара отсутствует.
- Учебный радар: 4 шкалы, North/Head Up, Gain, sweep, захват/сброс цели, CPA/TCPA, EBL/VRM. Идеальные измерения с частотой 1 Гц; это не реализация оценивателя реального ARPA.
- Учебная ECDIS: синтетический берег/глубины, GPS, путь, трафик, маршрут с добавлением/перетаскиванием/удалением точек, XTD, упрощённая проверка маршрута. Карта не является ENC.
- Три стартовые ситуации, закат/ночь/туман, отказ GPS, пауза и ускорение 1/2/4/8×.
- Сохранение/восстановление состояния в localStorage этого браузера и включаемый синтезированный звук двигателя.

## Управление

| Действие | Клавиша |
|---|---|
| Вперёд / влево / вправо / к штурвалу | F1 / F2 / F3 / F4 |
| Радар / ECDIS / телеграф / conning | F5 / F6 / F7 / F8 |
| Навигационные приборы | F10 |
| Руль ±5° / прямо | ← / → / 0 |
| Пауза | Space |
| Вернуться на мостик | Esc |
| Справка | H |

Радар: нажмите отметку цели для сопровождения; EBL/VRM включает измерение щелчком. Карта: Edit Route включает добавление точек щелчком и перемещение существующих перетаскиванием; выбранную точку можно удалить кнопкой DELETE WP (минимум две точки). Симуляция продолжает работать при открытых приборах.

## Архитектура

- `simulation/` — единственное авторитетное состояние, фиксированный шаг 1/60 с, динамика, трафик, координаты, CPA, датчики 1 Гц, сохранения.
- `instruments/` — Canvas2D радар и карта, преобразования координат и проверка синтетического маршрута.
- `rendering/` — React Three Fiber, 3D-геометрия и материалы, океанический shader, камера; читает ту же симуляцию.
- `components/` — штурвал и телеграф; `App.tsx` — рабочее пространство, станции, настройки и сеансы.
- `tests/` — математические и интеграционные регрессии, браузерные сценарии Playwright.

Графика и время симуляции независимы. Накопленное время не отбрасывается; за вызов выполняется до 600 шагов, остаток обрабатывается следующими кадрами. DPR ограничен 1.6, геометрия процедурная, ресурсы не загружаются из сети. 60 FPS — цель на подходящем GPU, не обещание для любого оборудования; браузерная проверка в среде использует программный SwiftShader.

## Проверки

```sh
npm test
npm run build
npm ci --prefix .agents/skills/marine-navigation-qa/scripts
MARINE_CPA_MODULE="$PWD/src/simulation/cpa-adapter.mjs" npm test --prefix .agents/skills/marine-navigation-qa/scripts
# Сначала запустите npm run dev в другом терминале:
npm run test:e2e
```

Браузерные тесты используют `/usr/bin/chromium`; путь и параметры можно изменить в `playwright.config.ts`. Тесты вызывают production-функции, включая исходный CPA через адаптер, проверяют матрицу FPS 15/30/60/144 × ускорение 1/2/4/8, инерцию, курс/COG/SOG, датчики и интеграцию управления с CPA/следом.

## Ограничения этапа

Модель судна **некалиброванная**; это учебная аппроксимация Nomoto, а не подтверждённая гидродинамика конкретного балкера. Датчики идеальные, без шума и транспортной задержки. Карта вымышленная; географическая привязка — локальная аппроксимация. Погода меняет визуализацию, но не силы ветра/волн. Traffic avoidance — ограниченная эвристика, не полная реализация МППСС-72. Автопилот удерживает heading, а не маршрут. F9/VHF, реальные ENC/S-57/S-63, полноценный ARPA, анализ результатов, replay, редактор сценариев, 15 уроков, банковый эффект/squat и sea-trial калибровка не реализованы. Сертификация IMO/IEC и точная эмуляция прошивки Furuno не заявляются.

Подробности уравнений и допусков: [docs/MODEL.md](docs/MODEL.md). Правила и исходный Skill с тестами сохранены.
